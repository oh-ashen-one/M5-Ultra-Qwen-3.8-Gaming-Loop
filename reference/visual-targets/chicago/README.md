# Chicago visual targets

These five owner-supplied AI-generated images are aspirational art direction, **not actual game output, game textures or proof of playability**. Each was materialized through Library, opened and visually inspected. The private machine-local `manifest.json` preserves Library identity, exact file hashes and stable relative paths. Image files and Library metadata are excluded from public Git; their local use is authorized, but public sharing of these exact files is not approved.

| Image | Inspected visual goals |
| --- | --- |
| `chicago_01_neighborhood_on_foot.png` | Brick/stone two-flats, stoops and railings, autumn canopy, dense sidewalk life, a third-person walking camera, L crossing and skyline depth |
| `chicago_02_downtown_l_driving.png` | Riveted steel elevated structure, repeated supports and strong patterned daylight, dense street walls, low chase camera and a cobalt-blue coupe |
| `chicago_03_alley_combat.png` | Brick service alley, rear porches/fire stairs, garages and ground wear, shoulder camera, cover readability and warm late-day light |
| `chicago_04_riverwalk_bridge.png` | Layered pedestrian levels, iron railings, stone bridge house, steel bridge, dense skyline, reflective river and sunset depth |
| `chicago_05_rainy_night_driving.png` | Wet-road reflections, warm streetlights under the L, blue/red pursuit accents and legible night silhouettes |

Geography is illustrative. Vehicle designs, plates and wanted-star slots vary across targets: use one original canonical coupe and a consistent five-slot HUD. Badges, text and plates are not texture sources. The daytime street is the first production target; river/night/rain are scoped extensions after the core route works. Local Qwen must author all game meshes/materials/rigs/animation in Blender.

Controller prompts explicitly label TARGET versus ACTUAL UNITY CAPTURE. Actual output lives under immutable per-candidate evidence IDs, never in this reference directory.
